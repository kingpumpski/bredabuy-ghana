# PHASE 13 — ADMIN RECONCILIATION

Reconcile the admin application.

Required areas:

- dashboard
- users
- customers
- sellers
- products
- categories
- brands
- inventory
- orders
- payments
- refunds
- logistics
- returns
- reports
- marketing
- CMS
- settings

Requirements:

- centralized admin guard
- permission-aware actions
- destructive actions require confirmation
- tables support loading/error/empty states
- sensitive data is not unnecessarily exposed
- audit-sensitive actions should use backend services
- admin screens must not bypass service boundaries
