# PHASE 17 — ASYNC STATE UX

Create a consistent application-wide approach for:

Loading
Empty
Error
Success
Retry

Apply it to:

- catalogue
- product details
- cart
- checkout
- orders
- payments
- wallet
- account
- seller
- logistics
- admin

Do not show blank screens.

Errors should explain:

- what happened
- what the user can do
- whether retry is available

Do not expose raw backend errors to customers.
