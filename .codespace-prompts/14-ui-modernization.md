# PHASE 14 — UI SYSTEM MODERNIZATION

Modernize the UI without changing business logic.

Use the existing BredaBuy identity.

Design direction:

PRIMARY
- Forest Green

ACCENT
- Ghana-inspired Gold

SECONDARY
- restrained Kente-inspired red

SURFACE
- warm cream / neutral backgrounds

TEXT
- charcoal / neutral dark tones

Requirements:

- establish design tokens
- consistent radius
- consistent spacing
- consistent typography
- modern cards
- modern tables
- subtle shadows
- meaningful icons
- responsive navigation
- mobile bottom/action patterns where appropriate
- polished empty/loading/error states
- hover/focus states
- reduced visual noise

Avoid excessive gradients.
Avoid excessive animation.
Avoid generic template-looking dashboards.

Do not create a separate CSS architecture if one already exists.
Extend the existing design system.
