# PHASE 19 — DEAD CODE AND DUPLICATE CLEANUP

After the architecture is stable:

Identify:

- duplicate pages
- duplicate services
- duplicate contexts
- duplicate types
- dead components
- unused imports
- abandoned routes
- obsolete placeholder files
- obsolete temporary scripts

Do not delete a file merely because it is not imported immediately.

Confirm whether it belongs to:

- routing
- lazy loading
- dynamic imports
- tests
- documentation
- future backend integration

Only remove confirmed dead code.

Document significant removals.
