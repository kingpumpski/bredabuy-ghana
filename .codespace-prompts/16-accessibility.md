# PHASE 16 — ACCESSIBILITY RECONCILIATION

Audit important customer, seller and admin interfaces.

Fix:

- missing labels
- inaccessible buttons
- keyboard navigation
- focus states
- dialog focus trapping
- aria attributes
- semantic headings
- form error announcements
- table semantics
- icon-only button labels
- color contrast

Target WCAG 2.2 AA principles where practical.

Do not sacrifice usability for excessive ARIA.
Prefer semantic HTML.
